# Upstream permission record

Original project: [Sam Becker's EXIF Photo Blog](https://github.com/sambecker/exif-photo-blog).

Copyright (c) Sam Becker and contributors.

The upstream repository does not currently provide an application LICENSE file.
The permission for this adaptation is recorded in
[issue #398](https://github.com/sambecker/exif-photo-blog/issues/398).

Strtus requested permission to publish the modified application, distribute its
source for non-commercial self-hosting, and allow further modification and
redistribution. On 2026-08-26,
[Sam Becker replied](https://github.com/sambecker/exif-photo-blog/issues/398#issuecomment-5426588048):

> You are welcome to fork this repo as a derivative project

His reply described the goal of enabling self-hosting in mainland China's
network environment and accepted the proposed attribution:

- Clearly credit EXIF Photo Blog.
- Link prominently to the original repository.
- Identify the adaptation as unofficial and community-maintained, focused on
  self-hosting in mainland China.

The reply did not specify a standard license. The original request and reply
remain the record of the permission for the upstream material; this file
summarizes that record rather than issuing a new upstream license.

The [PolyForm license](LICENSE.md) for Strtus-owned contributions does not apply
to or relicense the upstream code. See [NOTICE.md](NOTICE.md) for the scope of
each component's terms.
